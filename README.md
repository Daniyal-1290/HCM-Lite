# HCM Lite — Human Capital Management System

A lightweight, web-based Human Capital Management (HCM) system designed to simplify HR operations through centralized employee management, attendance tracking, leave management, payslips, and HR analytics.

## Overview

HCM Lite aims to make everyday human resource operations more organized and accessible. The application combines essential HR functionality with a dashboard that helps users explore employee data and view key workforce insights.

Developed as a hackathon project, HCM Lite demonstrates how web technologies and data analysis can be combined to build a practical HR management solution.

## Key Features

- **Employee Management** — View and manage employee records.
- **Role-Based Interfaces** — Separate employee and administrator experiences.
- **Attendance Management** — Access attendance-related functionality.
- **Leave Management** — Manage leave requests and their status.
- **Payslip Management** — Present employee salary and payslip information.
- **HR Dashboard** — Display workforce statistics and visual summaries.
- **Data Analysis** — Clean and explore HR data to identify useful patterns.
- **Face Recognition Demo** — Demonstrate a camera-based identity verification concept.

*Feature availability depends on the current project implementation and configuration.*

## Technology Stack

| Technology | Purpose |

## Getting Started

### Prerequisites

- A modern web browser.
- A code editor, such as Visual Studio Code.
- A local web server for features that require browser permissions or local resource loading.

## Usage

1. Open the application.
2. Sign in through the available login interface.
3. Access the appropriate employee or administrator pages.
4. Explore employee records, attendance, leave management, and payslip functionality.
5. Review the dashboard and available HR analytics.

Use the demo credentials or login process configured in your project. Do not publish real passwords or confidential employee information.

## Security and Privacy

HCM Lite is a hackathon project and should not be assumed to be production-ready.
